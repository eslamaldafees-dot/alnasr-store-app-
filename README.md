# البسة واكسسوارات النصر - Offline Prototype

نسخة تعمل بدون Supabase وبدون خادم.
- تبدأ بدون منتجات.
- اسم العميل عند أول دخول.
- لوحة إدارة محلية.
- كلمة مرور الإدارة: 2010 (للنموذج فقط).
- مسؤولان يمكنهما استخدام نفس الهاتف/النسخة، لكن البيانات لا تتزامن بين هاتفين.
- الأقسام الأربعة.
- الدفع عند الاستلام.
- لا توجد خدمة توصيل.
- رقم واتساب يحفظ محليًا من لوحة الإدارة.
- استقبال نص مشاركة من واتساب عبر Android SEND intent.

مهم: هذه نسخة محلية تجريبية. إذا أردت مشاركة المنتجات والطلبات بين هاتفين مختلفين، يلزم Backend.
